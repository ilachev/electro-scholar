# TOE reverse engineering and KMP rewrite

Репозиторий содержит воспроизводимое извлечение данных из 16-битной программы
«ТЕСТ» и первый рабочий инкремент новой версии на Kotlin Multiplatform.

## Каталоги

- `tools` — декодер базы, анализатор изображений, валидатор IR и Ghidra-скрипты.
- `analysis` — SQLite-экспорт, инвентарь изображений и контракты технических
  данных.
- `kmp-app` — Compose Multiplatform desktop-приложение.
- `dist` — сведения о локальной checkpoint-сборке.
- `test` — оригинальные файлы; намеренно исключены из Git.

Текущий результат и команды проверки: `CHECKPOINT.md`.

Следующая самостоятельная подсистема — Technical Document Lab. Она преобразует
изображения в проверяемые наблюдения, формулы и графы электрических схем, а
человек подтверждает неоднозначные решения. Текущий контракт и команды описаны
в `analysis/TECHNICAL_DATA.md`; план формул находится в
`kmp-app/docs/LATEX_MIGRATION_PLAN.md`.
