# TOE reverse engineering and KMP rewrite

Репозиторий содержит воспроизводимое извлечение данных из 16-битной программы
«ТЕСТ» и первый рабочий инкремент новой версии на Kotlin Multiplatform.

## Каталоги

- `tools` — декодер базы и Ghidra-скрипты.
- `analysis` — описание формата и экспортированная SQLite-база.
- `kmp-app` — Compose Multiplatform desktop-приложение.
- `dist` — сведения о локальной checkpoint-сборке.
- `test` — оригинальные файлы; намеренно исключены из Git.

Текущий результат и команды проверки: `CHECKPOINT.md`.

Следующая самостоятельная подсистема — Formula Lab: универсальный offline-
конвейер image-to-LaTeX с автоматической проверкой, историей ревизий и
обязательным подтверждением человеком. План находится в
`kmp-app/docs/LATEX_MIGRATION_PLAN.md`.
